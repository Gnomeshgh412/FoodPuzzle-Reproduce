# Optimized Agent v15 反事实双门验证器离线审查

## 结论

v15 低容量 `Add Necessity + Remove Safety` 双门验证器 **未通过准入，且显著差于 v14 Phase 1**。

代码已按预先规定的风险规则自动将双门策略设为 disabled，推理保持 H1。本轮未调用 API，未写入或覆盖正式结果。

## 预注册设计

- 冻结 H1、v14 Action Bank 和 Scientist Top-5。
- 不使用 UniMol。
- 对每个 Top-5 atomic swap 分别预测：
  - `P(add_is_necessary)`；
  - `P(remove_is_safe)`。
- 基础动作特征由未见 held-out 完整谱的外层模型生成。
- 验证器只用其他外层折的动作训练，形成 stacked OOF。
- 特征仅包含通用动作信号：官能团增删账本、检索支持、H1 边界和集合覆盖。
- 同时通过 add/remove 两门时最多执行一次交换，否则 `KEEP_H1`。
- 阈值仅从预先固定的 `{0.50, 0.60, 0.70, 0.80, 0.90}` 网格中选择。
- 运行固定 `PYTHONHASHSEED=0`。

## 离线 OOF 结果

| 指标 | v14 | v15 |
|---|---:|---:|
| 宏平均官能团 F1 增益 | +0.00794142 | +0.00481096 |
| 正收益动作 | 93 | 68 |
| 负收益动作 | 59 | 62 |
| 平局/保持 H1 | 416 | 438 |

v15 相对 v14 的平均增量为 `-0.00313046`，配对 bootstrap 95% 下界为 `-0.00670247`。v15 自身收益的 bootstrap 95% 下界为 `+0.00197408`，但这只说明它相对 H1 有小幅正收益，不能弥补它明显差于 v14 的事实。

### 折级增益

| 折 | v15 增益 | Add 阈值 | Remove 阈值 |
|---|---:|---:|---:|
| 0 | +0.00063736 | 0.8 | 0.9 |
| 1 | +0.00112739 | 0.8 | 0.5 |
| 2 | +0.00320440 | 0.8 | 0.9 |
| 3 | +0.01326647 | 0.8 | 0.9 |
| 4 | +0.00590292 | 0.7 | 0.9 |

Remove 阈值在折 1 从其他折的 0.9 降到 0.5，显示 remove-safety 概率不稳定，不适合被解释为跨谱可迁移的置信度。

## 失败机制

v15 原本假设，将 add 与 remove 拆开后，低容量统计特征可以区分正负动作。OOF 结果否定了这个假设：

- 双门少保留了 25 个正收益动作；
- 负收益动作没有减少，反而从 59 增至 62；
- 因此问题不是“总分未拆分”本身，而是现有静态统计特征缺少判断某个官能团在具体食物中是否必要的独立信息。

换句话说，v14 的动作错误在事后可以用 add/remove 账本解释，但“事后可解释”不等于“事前可预测”。当前的检索支持和边界特征无法稳定提供这个信息。

## 准入规则核对

| 准入条件 | 结果 |
|---|---|
| 相对 v14 配对 bootstrap 下界 > 0 | 失败（-0.00670247） |
| v15 自身 bootstrap 下界 > 0 | 通过（+0.00197408） |
| 负动作至多 29 | 失败（62） |
| 五折无系统性负收益 | 通过 |

总体准入：**否**。

## 对下一轮瓶颈审查的启示

本轮已经证明：

1. 继续对同一批静态统计特征做更复杂的分类、加权或阈值搜索，很可能继续过拟合。
2. 直接换成更大的分类器不是合理的下一步。
3. 真正缺失的是 action-specific 外部或语义证据，而官方离线 evidence 的直接分子链接又只覆盖 19.37% 训练查询。
4. 下一轮应回到瓶颈审查，重点判断：在不恢复联网搜索的约束下，现有数据是否还有未使用的 action-specific 信号；如果没有，应承认离线设定下的可辨识性上限，而不是继续叠加 Agent 层。
