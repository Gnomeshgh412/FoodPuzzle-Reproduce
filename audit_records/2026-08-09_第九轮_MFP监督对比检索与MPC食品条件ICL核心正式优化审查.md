## 二、MFP

### 2.1 当前主要瓶颈

当前输入只包含分子集合，输出必须是具体食物。train 与 dev 具体食物名称没有交集；71 条 dev 只有 53 个唯一分子谱，且第七、八轮开放 Scientist 的具体食物 Top3 均为 0。历史较高宏类别成绩主要来自直接类别预测，不符合当前任务输出约束。

本轮据此把瓶颈定位为：在封闭数据中无法辨识未见具体实体，但 BM25 Top30 中常存在宏类别正确、分子谱相近的具体训练食物，因此需要验证一种不在推理时预测类别的具体食物类比排序。

### 2.2 第一性原理与文献对应

- 新方法没有增加外部食品知识，只增加“同宏类别食品的分子集合应在任务度量中接近”的监督归纳偏置；
- Deep Sets（NeurIPS 2017）支持集合表示的置换不变性，但不保证未见实体恢复；
- Supervised Contrastive Learning（NeurIPS 2020）支持同标签样本拉近、异标签样本推远，但不证明类别几何足以排序 FoodPuzzle 的具体食品；
- Uni-Mol（ICLR 2023）支持冻结分子三维表示向下游任务迁移，但不提供食品身份知识；
- 因此本轮只把这些文献作为表示和损失设计依据，最终结论完全由预注册 OOF 证伪。

原始来源：

- Deep Sets：https://papers.nips.cc/paper/2017/hash/f22e4747da1aa27e363d86d40ff442fe-Abstract.html
- Supervised Contrastive Learning：https://proceedings.neurips.cc/paper/2020/hash/d89a66c7c80a29b1bdbab0f2a1a94af8-Abstract.html
- Uni-Mol：https://openreview.net/forum?id=6K2RM6wVqKu

### 2.3 冻结实验

- 对照：train-only BM25 Top1 具体食物；
- 候选：冻结 BM25 Top30 具体食物；
- 唯一改动：以 IDF 加权 UniMol 均值与标准差构造置换不变集合特征，训练线性监督对比投影，再在 Top30 中直接检索具体食物；
- 固定超参数：投影维度 128、温度 0.1、学习率 `1e-3`、200 轮、种子 20260808；无搜索；
- 数据：567 条 train，按完整分子谱分组五折 OOF；只有 OOF 通过才允许运行一次 dev；
- 准入：宏类别增益 bootstrap 95% 下界大于 0、至少 4/5 折非负、平均分子 Jaccard 至少保持 BM25 的 90%；dev 需再次满足增益下界和相似度安全门；
- 禁止：不调用 LLM、不输出或在推理时输入宏类别、不使用类别 posterior、不改 Reviewer、不读取正式 test。

### 2.4 实施事实

- 首次试运行发现 567 条训练数据中 5 条食物无法由 FlavorDB 映射宏类别；实验没有伪造标签，也没有删除其具体食物候选资格，而是只把这 5 条排除出监督对比损失，仍保留为 BM25 候选；这是标签缺失处理，不改变候选、损失或冻结超参数；
- 修正后完成 567 条 exact-profile grouped OOF；没有运行 dev；API 调用为 0。

### 2.5 结果

| 指标 | BM25 | 监督对比检索 | 差值/说明 |
|---|---:|---:|---:|
| 宏类别 accuracy | 0.377425 | 0.356261 | -0.021164 |
| 具体食物 accuracy | 0.000000 | 0.000000 | 0 |
| 平均分子 Jaccard | 0.661096 | 0.655842 | 保持 99.205% |
| Top30 宏类别 oracle | — | 0.906526 | 候选供给充足 |

- 宏类别增益 bootstrap 95% 区间：`[-0.056437, 0.017637]`；
- 各折增益：`[-0.061404, -0.061404, 0, -0.008850, +0.026549]`，只有 1/5 折为正；
- 改对/改错/不变：`53/65/449`；
- OOF 未通过，因此按预注册停止，未查看 dev 结果。

### 2.6 MFP 结论

**未通过并停止。** 同类别监督可以基本保持化学相似度，却没有提高具体食物类比的类别正确性。Top30 oracle 很高但学习排序下降，说明“同宏类别形成统一 UniMol 集合几何”不是当前可用的选择机制。不得继续调整温度、投影维度、训练轮数或在该度量上追加 Reviewer 来挽救本轮。

## 三、MPC

### 3.1 当前主要瓶颈

568 条 train 的目标食品全部不同；每条平均仅给出 9.03 个 partial 分子，却平均需要恢复 75.70 个分子，缺失比例约 86.87%。当前 H1 具有较高召回和 exact-N，但主要由 occurrence/co-occurrence 驱动，缺少目标食品名称所提供的食品条件信息。历史 BM25-ICL 具有更高精度与分子多样性，但经常不满足 exact-N。

因此本轮瓶颈定位为 Scientist 缺少食品条件化的高精度具体分子核心，而不是 Reviewer 选择失败。

### 3.2 第一性原理与文献对应

- FoodPuzzle 原文使用目标食品、partial、N 和 BM25 训练示例驱动 Scientist，直接支持食品条件化 ICL 输入；
- RAG（NeurIPS 2020）支持参数记忆与检索到的非参数记忆互补，但不规定本项目的集合合并规则；
- Predict and Constrain（ICML 2018）与 Conditional Set Generation（EMNLP 2022）支持集合内容预测与 cardinality 约束需要同时处理；
- 文献不直接证明“ICL 核心 + H1 补足”，因此本轮把该规则冻结为可证伪假设，而不是引用文献替代实验。

原始来源：

- FoodPuzzle：https://arxiv.org/html/2409.12832
- RAG：https://proceedings.neurips.cc/paper/2020/hash/6b493230-Abstract.html
- Predict and Constrain：https://proceedings.mlr.press/v80/brukhim18a.html
- Conditional Set Generation：https://aclanthology.org/2022.emnlp-main.324/

### 3.3 冻结实验

- 对照：第七轮当前 H1 dev 预测与同一官方口径逐样本结果；
- Scientist：官方现有 BM25-ICL Prompt，输入只含 `target_food`、`partial_molecules`、`n` 和 train-only Top3 示例；
- 唯一改动：规范化、去重并排除 partial 后，ICL 有序具体分子核心优先；不足 N 时按冻结 H1 排名补足，超过 N 时按 ICL 原顺序截断；
- Reviewer、H1 训练与特征、候选宇宙、官能团词表和评测器全部冻结；
- 数据：71 条 dev；不读取正式 test；
- API 上限：71 次 Scientist；预测冻结后最多 500 个未缓存分子的官能团映射；
- 准入：exact-N 71/71；官方 F1 增益 bootstrap 下界大于 0；具体分子 F1 均值不下降且区间下界不低于 -0.002；至少 4/5 固定分块非负；分子多样性至少保持 H1 的 90%。

### 3.4 实施与 API 事实

- Scientist 成功调用 71 次，没有将 dev `missing_molecules` 发送给模型；66 条解析成功、5 条解析失败；失败样本按冻结规则完全回退 H1，没有重试 Prompt；
- 混合集合 71/71 满足 exact-N；平均 ICL 核心 62.676 个，平均 H1 补全 11.282 个；
- 混合预测包含 669 种不同分子。独立复制第七轮 dev 官能团缓存后已有 356 种命中，新调用 313 次官能团映射，低于 500 上限；旧缓存未覆盖；
- 总 DeepSeek 成功请求为 384 次：Scientist 71 次、官能团映射 313 次；原始 ICL 复评全部命中新独立缓存，新增映射调用为 0。

### 3.5 结果

| 指标 | 当前 H1 | 原始 ICL | ICL核心+H1补全 |
|---|---:|---:|---:|
| 官方官能团 Precision | 0.593366 | 0.581444 | 0.619498 |
| 官方官能团 Recall | 0.750115 | 0.695225 | 0.755585 |
| 官方官能团 F1 | 0.649100 | 0.620125 | 0.667465 |
| 具体分子 Precision | 0.694117 | 0.663485 | 0.707518 |
| 具体分子 Recall | 0.694117 | 0.643105 | 0.707518 |
| 具体分子 F1 | 0.694117 | 0.651984 | 0.707518 |
| exact-N | 71/71 | 43/71 | 71/71 |
| 不同预测分子数 | 465 | 663 | 669 |

- 相对 H1 官方官能团 F1 平均增益：`+0.018365`，bootstrap 95% 区间 `[-0.001354, 0.039184]`；
- 相对 H1 具体分子 F1 平均增益：`+0.013543`，区间 `[-0.023237, 0.055368]`；
- 五个固定分块官方增益：`[+0.023109, +0.034001, +0.034869, +0.019952, -0.020446]`；
- 逐样本官方 F1 改善/下降/不变：`25/14/32`；
- 5 条 Scientist 解析失败样本完全回退 H1，增益均为 0；66 条解析成功样本平均官方增益为 `+0.019756`；
- 收益并非单纯来自补齐 N：原始 ICL 本轮 F1 只有 0.620125，而混合方法同时提高官能团 Precision、Recall、具体分子 F1 和分子多样性；但少数样本存在大幅退化，导致两个关键稳定性区间均未通过。

### 3.6 MPC 结论

**获得局部信号但暂不准入。** 食品条件化 ICL 确实补充了 H1 缺失的真实信息，平均官方指标和具体分子恢复同时提高，且 exact-N 与多样性正常；但官方增益区间仍跨零，具体分子安全区间明显低于冻结下界，存在 14 条退化样本。因此不得把该混合方法写入当前正式主版本，也不得围绕 Prompt、BM25 K 或固定占比继续调参。

本轮留下的新证据是：MPC 的问题已经从“Scientist 完全没有食品条件信息”推进为“食品条件 ICL 与 H1 的相对可靠性随查询变化，但当前无 Gold 的条件下没有可靠选择机制”。这只能作为下一轮重新定位的对象，不能在本轮追加门控器。
