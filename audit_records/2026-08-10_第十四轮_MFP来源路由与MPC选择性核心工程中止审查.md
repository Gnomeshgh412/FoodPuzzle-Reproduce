用户确认余额恢复并允许继续后，两个任务均从原逐样本账本断点恢复。恢复过程没有修改 Prompt、模型、输出 token、候选来源、解析器、数据切分或准入条件。

### 7.1 MFP：来源路由 Scientist 未通过并停止

- 71 个 dev ID 全部尝试；第一遍成功 62 个，同配置重试后唯一成功数增至 66；
- 剩余 5 个 ID（11、112、167、216、217）在后续同配置重试中持续失败；
- 失败不是余额或截断：Scientist 将“多分子证据候选”生成成 BM25 锚点相同或等价的具体食物，触发冻结的“三来源候选互异”检查；
- 例如 Brandy 的 BM25 锚点是 Papaya Brandy，Scientist 证据候选仍为 papaya brandy；Lingonberry 的 BM25 锚点是 Bilberry，证据候选仍为 bilberry；
- 这说明来源标签并没有在最相似食品上产生独立假设，反而把同一强信号重复包装成两个来源。问题属于方法结构性坍缩，而不是可忽略的格式噪声；
- 冻结要求为 71/71 可评测，因此没有用 66 条幸存样本运行官方类别映射，也没有计算不完整 Scientist oracle 或 Reviewer accuracy。

正式结论：**未通过并停止。** 不再继续调同一“强制三来源互异”提示词，也不通过放宽检查把重复候选伪装成来源多样性。

### 7.2 MPC：选择性高置信核心未通过并停止

- 完成 568/568 个严格 OOF ID 的首轮尝试，跨折违规为 0；
- 仅 376 个唯一 ID 得到合法输出，192 个 ID 持续失败；全部 576 条调用记录中有 189 次 JSON 解析失败，网络 SSL/IncompleteRead 错误合计 11 次；
- 192 个持续失败 ID 中，182 个末次仍是 JSON 解析失败，说明主体不是网络；
- 失败样本平均 N 为 113.875，成功样本平均 N 为 56.207，失败明显集中在大 N；
- 376 个成功样本的平均核心长度仍为 47.854，平均占 N 的 76.10%；141 条仍填满 N，235 条短于 N，59 条为空；
- 五折均有大规模失败：成功/失败依次为 78/36、83/31、71/43、77/36、67/46；
- 因此“允许短或空”没有稳定建立分子级弃权机制。对大 N 样本，模型仍倾向生成长列表并产生不可闭合 JSON；在成功样本中也有 37.5% 直接填满 N。

冻结要求是 568/568 可评测后才运行 Round12 排序器、Round13 gate 和 exact-N 对照。完整性门槛未满足，因此没有使用 376 条成功子集训练或报告指标，没有读取 dev Gold，也没有运行官方官能团评测。

正式结论：**未通过并停止。** 不再通过无限重试、扩大 token、容错拼接残缺 JSON 或修改同一自由列表 Prompt 挽救本轮。

## 八、本轮反思与下一轮边界

### MFP

本轮正确识别了 Scientist 候选召回是上游瓶颈，但把“来源不同”误当成了“假设必然不同”。当 BM25 类比与分子证据指向同一相近食品时，强制互异既违背证据，也导致接口失败。下一轮不能继续追求表面三样性；应重新审查哪些输入信号对官方宏类别确有互补信息，并允许证据一致时形成可审计的合并或置信分配。该方向尚未冻结、尚未获准。

### MPC

本轮从第一性原理上允许弃权是合理的，但把分子级选择压成一次自由生成长列表，缺少逐候选的局部决策结构。大 N 时生成长度本身成为瓶颈，且“少报”没有可靠发生。下一轮应重新审查 Scientist 的决策粒度：例如先对冻结候选逐项作可验证的保留/弃权判断，再由冻结执行器组集合，而不是继续要求一次性生成任意长核心。是否采用该方向仍需先做现状核验、第一性原理与文献查询，并重新获得用户允许。
