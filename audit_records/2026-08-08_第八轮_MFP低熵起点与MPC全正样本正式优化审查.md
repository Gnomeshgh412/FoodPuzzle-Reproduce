## 2. 瓶颈与第一性原理

### 2.1 MFP

MFP 输出是具体食物。第七轮开放 Scientist 的具体食物 Top3 召回为 0，正确实体不在候选时 Reviewer 的上限也是 0。第七轮理由又主要依赖在大量训练食物中共有的通用风味分子，因此本轮只检验“完整长列表造成错误搜索初始化”这一因果假设。

FoodPuzzle 原文要求按训练出现频率计算分子信息熵，并选择最多 10 个最低熵分子作为 MFP 搜索起点；其错误分析把不合适的搜索空间初始化列为最大错误类型（32%）。论文已发表于 KDD 2025，但公开正文没有给出熵公式或对应代码。因此本轮使用可复现的顺序等价定义：

`p_m = df(m) / Σ_j df(j)`，`h_m = -p_m ln(p_m)`。

训练集中最大 `p_m=0.0089738<1/e`，所以按最低 `h_m` 排序严格等价于按最低训练文档频率排序。本实现只称为与公开文字顺序等价的复现，不称为官方代码逐行复刻。

相关来源：

- FoodPuzzle（KDD 2025 / arXiv 公开正文）：https://arxiv.org/html/2409.12832
- *Lost in the Middle*（TACL 2024）：https://aclanthology.org/2024.tacl-1.9/

### 2.2 MPC

MPC 是查询条件化的 exact-N 多标签排序。训练候选宇宙覆盖 dev Gold 的 99.2192%，当前漏召回中 96.55% 已在候选宇宙内。源码却只保留 21.76% 的正样本 occurrence，1,596 个唯一正分子中有 620 个从未作为正样本参与训练；这些分子在 dev 的诊断召回为 2.07%。本轮因此只检验“随机正样本截断导致整体排序监督孔洞”这一假设。

相关来源及适用边界：

- ListMLE（ICML 2008）支持把查询内排序作为训练单位，但不直接证明本轮必须更换排序损失：https://icml.cc/Conferences/2008/papers/167.pdf
- F-measure optimization（JMLR 2014）说明 F1 是不可分解结构指标：https://www.jmlr.org/papers/v15/waegeman14a.html
- AttentionXML（NeurIPS 2019）支持重视极端多标签中的标签级相关输入和长尾标签，但不直接证明“保留全部正样本”必然有效：https://proceedings.neurips.cc/paper/2019/hash/9e6a921fbc428b5638b3986e365d4f21-Abstract.html

## 3. 冻结实验方案

### 3.1 MFP

- 对照：第七轮同一 DeepSeek 模型、同一 BM25 前二名、完整分子列表的开放第三候选；
- 变体：只发送最多 10 个低熵起始分子；
- 发送字段：样本编号、低熵起始分子、冻结 BM25 类比食品和固定任务指令；
- 明确不发送：真实食物、真实宏类别、原第三候选、评测结果和正式 test；
- 主诊断：Top3 具体食物召回；安全指标：Top3 宏类别 oracle 覆盖；
- 准入：相对第七轮具体食物召回增益的配对 bootstrap 95% 下界大于 0，且宏类别 oracle 平均不下降；
- 停止：具体食物仍为 0 或准入失败时，停止当前开放参数知识 Scientist 提示路线，不追加 Reviewer 和同轮调参。

### 3.2 MPC

- 数据：MPC train 568 条，按完整 profile 聚类的五折 OOF；
- 对照与变体均从同一主源码隔离加载；变体只删除 `selected_positives = selected_positives[:20]`；
- 冻结：同一 pairwise logistic H1、同一特征、每查询 30 个未标注负样本、每查询总权重 0.35、候选宇宙、exact-N、无 Reviewer/UniMol/Action Bank；
- 主指标：具体分子 F1 配对增益；安全指标：数据库官能团 F1 配对增益；
- 准入：具体分子 F1 增益 bootstrap 95% 下界大于 0且至少 3/5 折非负；平均官能团 F1 不下降且至少 3/5 折非负；全部 exact-N；
- 停止：任一条件失败即停止，不在本轮更换损失、调参或追加 Reviewer。

## 4. 实际实现与运行

本轮曾创建两份隔离实验脚本：

- `scripts/第八轮_MFP_官方低熵起点科学家验证.py`；
- `scripts/第八轮_MPC_全正样本H1科学家验证.py`。

两份脚本均通过 `py_compile`。MFP 发送前检查显示 71/71 样本均有 1–10 个合法起点，完整输入分子的平均训练文档频率为 `230.4066`，低熵起点为 `138.7767`。首次 MFP 调用受沙箱 DNS 隔离失败，成功调用数为 0；随后按已授权范围联网重跑，完成 71/71 次并逐条落盘。载荷中没有 Gold 字段，71 条响应的支持分子均未越出各自低熵起点。

MPC 运行完成 5/5 折、568/568 条。MFP 与 MPC 均未读取正式 test，未修改正式评测、正式结果或主版本，未执行 Git 写操作。

## 5. 结果

### 5.1 MFP：未通过并停止

| 指标 | 第七轮完整列表 | 第八轮低熵起点 | 变化 |
|---|---:|---:|---:|
| 有效响应 | 65/71 | 71/71 | +6 |
| 可映射宏类别的开放输出 | 2/71 | 10/71 | +8 |
| Top3 具体食物召回 | 0/71 | 0/71 | 0 |
| 开放 Top1 宏类别命中 | 0/71 | 7/71 | +7 |
| Top3 宏类别 oracle 覆盖 | 37/71 (`0.52113`) | 36/71 (`0.50704`) | -1/71 |

相对第七轮的具体食物召回增益为 0，bootstrap 下界为 0；宏类别 oracle 还下降 `0.01408`。正式准入失败。

第八轮 71 个输出有 47 个唯一名称，33 个样本使用重复答案；`薄荷茶` 单独出现 13 次，`牛肉汤` 出现 5 次。低熵筛选确实减少了通用分子干扰并改善格式完整性，但模型转而把少数显著气味线索过度映射到新的原型食物，没有获得实体辨识信息。这证明“证据注意力更集中”不等于“具体实体可恢复”。

结论：**未通过并停止当前开放参数知识 Scientist 提示路线**。不得继续围绕 Top-K、熵公式或同类提示措辞微调，也不得让 Reviewer 挽救不存在的正确实体。

### 5.2 MPC：未通过并停止

| 指标 | 正样本截断 H1 | 全正样本 H1 | 配对变化 |
|---|---:|---:|---:|
| 平均具体分子 F1 | `0.65881286` | `0.65880433` | `-0.00000853` |
| 平均数据库官能团 F1 | `0.89771398` | `0.89818746` | `+0.00047348` |
| exact-N | 568/568 | 568/568 | 不变 |

- 具体分子增益 bootstrap 95% 区间：`[-0.00011130, 0.00010166]`；
- 具体分子胜/负/平：`6/8/554`；五折增益为三正两负，但总体为负且区间跨零；
- 官能团增益 bootstrap 95% 区间：`[-0.00007485, 0.00149130]`；胜/负/平为 `2/1/565`；
- 只有 14/568 条样本的具体分子 F1 发生非零变化，正负相互抵消。

相关性诊断“零正监督标签召回很低”是真实的，但补齐 occurrence 没有改善整体排序。这说明随机 20 个正样本已足以确定当前全局线性 H1 的主要方向；剩余正样本没有提供当前特征能够利用的新查询条件信号。最大问题因此不再是正样本数量，而更可能是**现有特征对 food-conditioned 稀有分子需求不可辨识**。

结论：**未通过并停止全正样本方向**。不得继续调整正样本上限、采样种子或在同轮改成 ListMLE 来挽救该假设。

## 7. 下一轮重新定位

- MFP：搜索起点、开放提示、简单证据桥和名称词表路线均已连续失败。在不扩展数据的边界下，下一步不再生成新提示，而应先审查**现有规范食物目录中的实体是否可排序**：以 train-heldout 的实体链接/目录约束召回为实验前 oracle，判断 GENRE 式规范实体约束是否有可辨识信号；若无，则承认当前输入下 exact-food 不可解，转入用户允许的“合理具体食物类比、官方宏类别为主”后备目标。
- MPC：下一步先做现有 H1 特征的 query-level rankability 审查，比较漏掉 Gold 与错误 Top-N 分子在全局频率、共现、检索支持和食品条件特征上的 pairwise oracle/AUC；只有证明确实存在可分信号，才设计新的查询条件化排序器。若现有特征本身不可分，则离开 H1 训练细节，重新寻找新的 food-conditioned 信息来源。

上述只是下一轮审查方向，尚未获得新的实现或运行授权。
