# 第十轮：MFP 查询候选关系排序与 MPC 共识锚定候选效用正式优化审查

日期：2026-08-09  
结论：MFP 未通过并停止；MPC 获得稳定训练 OOF 信号和开发集局部正向信号，但未通过正式开发集稳定性门槛，停止且不准入主方法。

## 一、授权、边界与现状核验

用户在完整冻结方案后明确回复“允许”，并再次要求遵守既有双任务独立循环。本轮因此分别建立 MFP 和 MPC 的假设、输入、指标、停止条件与结论：不联合训练、不交换标签或结果、不读取正式 test、不增加外部数据、不修改正式评测器、不覆盖历史结果或缓存、不修改主版本、不进行 Git 写操作。

正式实施前核验：

- MFP 使用 `results/splits/mfp/train.jsonl` 的 567 条样本和 exact-profile grouped 五折；只有训练 OOF 通过才允许 dev；
- MPC 使用 `results/splits/mpc/train.jsonl` 的 568 条样本，按 partial+missing 完整谱签名 grouped 五折；只有训练 OOF 全部门槛通过才允许复用既有 71 条 dev ICL；
- MFP 输出始终是训练侧真实具体食物名称；MPC 输出始终是 exact-N 具体分子集合；
- 两项唯一变化均为排序机制。候选生成、数据切分、官方映射、正式 test 和主执行器均冻结。

## 二、第一性原理与文献对应

### 2.1 MFP

当前输入只包含完整分子集合，正确输出是具体食物；567 条 train 只有 376 个不同分子谱，而且 200 条样本所在的完全相同分子谱跨宏类别。模型无法从完全相同输入恢复互相矛盾的具体实体标签，这是不可消除的信息上限。另一方面，BM25 Top30 的宏类别 oracle 为 0.906526，说明候选覆盖并非首要瓶颈；现有 BM25、Jaccard 和 UniMol 双向集合相似度对正确类别候选有弱到中等可分性。因此本轮只检验：全局对比几何失败后，查询内非对称关系排序是否能更好利用已有真实分子信号。

借鉴边界：

- RankNet（ICML 2005）支持用候选对相对偏好训练排序器：https://www.microsoft.com/en-us/research/publication/learning-to-rank-using-gradient-descent/
- Listwise Learning to Rank（ICML 2008）强调排序目标应匹配查询内候选列表：https://icml.cc/Conferences/2008/papers/167.pdf
- Query-Level Stability（ICML 2008）说明学习排序需要按查询层面审查泛化：https://icml.cc/Conferences/2008/papers/179.pdf

这些工作只支持“查询内监督比全局表示更贴近排序决策”的归纳偏置，不保证 FoodPuzzle 存在稳定增益，也不能解除相同输入跨标签冲突。

### 2.2 MPC

当前 H1 能稳定给出 exact-N 且总体召回较高；食品条件 ICL 提供 H1 没有的目标食品语义，但第九轮固定合并使微观 Gold 命中由 4064 降到 4019。逐分子诊断进一步显示：H1 与 ICL 共识候选 precision 为 0.949463，而 ICL-only 为 0.214499、H1-only 为 0.439712。由此最大瓶颈不是查询级 Reviewer，而是如何保留高可靠共识，并在两个来源不一致时判断具体分子的真实效用。

借鉴边界：

- Recall-then-Verify（ACL 2022）支持先扩大候选召回、再对候选真实性验证：https://aclanthology.org/2022.acl-long.128/
- Learning to Defer（ICML 2020）和 Post-hoc Deferral（NeurIPS 2022）支持显式学习不同信息源何时可靠：https://proceedings.mlr.press/v119/mozannar20b.html ，https://proceedings.neurips.cc/paper_files/paper/2022/hash/bc8f76d9caadd48f77025b1c889d2e2d-Abstract-Conference.html
- Calibrated Surrogate Maximization of Linear-fractional Utility in Binary Classification（ICML 2020）说明 F-measure 一类集合效用需要校准审查：https://proceedings.mlr.press/v119/zhang20w.html

本轮没有照搬分类 defer 或直接优化官能团 F1；训练标签只是真实具体缺失分子，官方官能团 F1 只在具体分子集合冻结后评测。

## 三、冻结方法

### 3.1 MFP 唯一改动

- 候选固定为 BM25 Top30；训练查询自身只按行 ID 排除；
- 特征固定为 query-normalized 的 BM25、Jaccard、UniMol profile cosine、query-to-food Chamfer、food-to-query Chamfer；
- 同一查询内，同宏类别具体食物候选应排在异宏类别具体食物候选之前；宏类别只产生 train-only pair label，不作为推理特征或 posterior；
- 模型固定为 L2 LogisticRegression，`C=1`、`fit_intercept=False`、`liblinear`、seed 20260809；不搜索特征或超参数；
- 准入：宏类别 accuracy 配对 bootstrap 95% 下界大于 0、至少 4/5 折非负、具体食物 accuracy 不下降、平均结构相似度至少保持 BM25 的 90%；任一失败即停止，不运行 dev。

### 3.2 MPC 唯一改动

- 为 568 条 train 查询各生成一次严格 OOF 的 BM25-ICL Scientist 输出；query 只含 target_food、partial_molecules、N，Top3 demo 只来自该 query 外折 fit，允许 demo 使用其自身训练标签；
- Prompt、DeepSeek 模型、BM25 K=3、H1、候选宇宙均冻结；解析失败记为空，不改 Prompt；传输错误只原样重试；
- 候选池为 H1 TopN 与 ICL 的并集；跨源共识候选锁定；剩余候选按 H1 倒数名次、ICL 倒数名次、跨源共识、H1 occurrence score 四项特征排序；
- 候选效用标签只表示该具体分子是否属于 held-out 真实 missing 集合；排序器与 MFP 同为固定 L2 LogisticRegression；
- 第二层严格 OOF：每折 Reviewer 只用另外四折的候选标签训练，再预测当前折；
- 训练准入：query-wise residual AUC 下界大于 0.5，宏/微具体分子 F1 增益下界均大于 0，至少 4/5 折非负，568 条全部 exact-N；
- 训练全部通过后才复用第九轮 71 条 dev ICL、第七轮 H1 和第九轮独立官能团缓存；若出现未缓存分子即停止，不新增官能团调用；开发准入要求官方官能团 F1 增益下界大于 0、具体分子宏/微指标不下降、至少 4/5 固定分块非负、71 条 exact-N。

## 四、执行完整性

- MFP 完成 567 条五折 OOF，未调用 API；
- MPC 完成 568 个语义 Scientist 查询；529 条解析成功、39 条解析失败并保留为空；发生 1 次瞬时传输错误，对同一请求原样重试后成功；
- `训练OOF_ICL核心.jsonl`、`训练OOF检索账本.jsonl`、训练 split 和 OOF 审查结果均为 568 个唯一且完全一致的 ID；
- 568 条检索账本共 1704 个 query-demo 关系，跨折违规为 0；
- 训练 OOF 568/568 exact-N，开发集 71/71 exact-N；
- 开发集所有最终候选均命中第九轮独立官能团缓存，新官能团 API 调用为 0；
- 没有运行正式 test，没有覆盖历史产物，没有修改主代码。

五折宏类别增益依次为 `+0.026316 / +0.008772 / +0.008850 / -0.017699 / -0.061947`，只有 3/5 折非负。虽然具体食物能力未进一步下降、结构相似度充分保持，但主指标均值下降且置信区间跨零，因此未通过并停止，未运行 dev。

机制结论：合法的查询—候选关系特征确实能改变局部排序，但没有稳定解决宏类别排序；第五折退化尤其明显。连续两轮监督排序思路均未形成稳定收益，下一轮不得继续在相同五特征、同类 pairwise loss 上调参。候选覆盖高不等于可辨识，完全相同谱跨类别以及弱关系信号仍是主要限制。
