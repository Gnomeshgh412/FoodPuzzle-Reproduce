# MPC 冻结结构代理查询级执行器 OOF 审计

> **结论撤销（2026-08-01）**：本记录中的结构执行器在选择 held-out 查询动作时直接计算了 proposal 与该查询 Gold 官能团之间的 F1，构成目标泄漏。`+0.0169`、16 个负收益动作及“通过准入”等结论均不得作为合法方法结果。无泄漏重算只有 `+0.00751`，详见 `2026-08-01_mpc-structure-route-leakage-correction-and-legal-audit.md`。本文保留以记录错误来源。

## 1. 审计目标

上一轮已经证明，冻结的 SMILES/SMARTS 官能团感知层比 FlavorDB 字符串代理更接近正式 MPC 动作收益。本轮进一步回答：如果真正用该结构代理在 Scientist Top-5 中选择一个交换动作，查询级正式口径 F1 是否能够稳定提高。

本轮没有修改正式 Agent、调用 API 或覆盖正式结果。所有计算都在内存中完成，唯一新增产物是本审计记录。

## 2. 预注册执行策略

### 2.1 冻结内容

- 完全复用上一轮已经冻结的 45 个 SMARTS 和 7 个程序化分子图标签；
- 不依据本轮 cache 结果修改任何官能团定义；
- 不使用 UniMol；
- 不扩大 v14 Action Bank；
- 不改变 Scientist Top-5；
- 不增加 Reviewer、Fusion Agent 或 Multi-Agent。

### 2.2 动作规则

对每个查询：

1. 以 H1 为基线；
2. 对 Scientist Top-5 中每个 exact-N 单交换 proposal，计算冻结结构官能团代理的 `ΔF1`；
3. 选择结构 `ΔF1` 最大的动作；
4. 只有最大 `ΔF1 > 0` 时才执行；
5. 否则显式 `KEEP_H1`。

本轮没有使用可学习阈值。零效用门直接来自“只有代理效用严格为正才允许改变 H1”的决策定义，因此避免使用评测 cache 拟合阈值。

### 2.3 数据隔离

- Action Bank 和 Scientist Top-5：沿用完整谱聚类五折 OOF；
- 每个 held-out 查询的候选生成模型只使用其他折；
- functional-group cache：动作确定之后才用于只读重构正式口径收益；
- cache 没有参与候选生成、结构 ΔF1、动作排序或 `KEEP_H1` 判断。

## 4. 查询级正式口径结果

### 4.1 冻结结构执行器相对 H1

| 指标 | 结果 |

152 个实际交换中，105 个提高正式 F1，16 个降低，剩余 31 个在正式口径下打平。动作 precision 为 `105 / 152 = 69.08%`。

## 7. 为什么这次与 v1–v15 不同

此前大多数 MPC 优化都在以下同一闭环内发生：

1. 用 DB 字符串官能团代理定义动作好坏；
2. 根据该代理训练或筛选 Scientist/Reviewer/门控器；
3. 希望正式 LLM 官能团评测同步提高。

但动作级相关性只有约 0.39，因此增加模型复杂度只是在更精确地优化错误目标。

本轮没有增加 Agent 层，而是先修复决策所依赖的观测变量：从 SMILES 分子图确定与正式词表相容的离散官能团，再决定是否交换。结构代理将正式负动作从 72 降到 16，说明当前收益来自目标对齐，而不是从相同信号中继续堆叠推理。

## 8. 覆盖敏感性与不能回避的限制

### 8.1 已覆盖 511 个查询

结构执行器选择的 152 个动作全部存在于 cache，因此在这 511 个 H1 可评估查询内没有 selected-action 缺失。覆盖敏感性区间退化为同一个均值：`+0.01690120`。

### 8.2 未覆盖 57 个查询

由于 H1 本身缺少 cache，无法计算正式基线 F1。这 57 个查询不能被当作零收益，也不能由 DB 或结构代理代替正式结果。因此：

- 511 条结果不是完整 568 条训练查询的无偏估计；
- 下一次正式评测会对新分子调用 LLM 并补齐 cache，覆盖差异可能改变收益；
- 在没有 API 结果前，不能保证 71 条测试集也有相同增益。

### 8.3 研究者过拟合

虽然结构规则没有根据本轮结果调整，但 v13–v15 已多次观察同一训练 OOF。下一阶段不得再根据这 511 条结果调整 SMARTS、零门或候选数，否则会重新进入自适应过拟合。

## 9. 建议的正式接入方式

若获批准，下一阶段只做最小接入：

1. 将冻结的结构官能团识别封装进现有 `code/Only-Deepseek/optimized_agent.py`；
2. MPC 初始化时从 FlavorDB SMILES 构建只读结构官能团映射；
3. 保持现有 H1、Action Bank 和 Scientist Top-5；
4. 用冻结结构 `ΔF1` 选择至多一个动作；
5. 最大结构 `ΔF1 <= 0` 时保持 H1；
6. Reviewer 继续审查证据，但不得推翻结构 exact-N 与动作边界；
7. MPC 仍不读取 evaluation cache，仍不使用 UniMol；
8. `check-only` 必须验证 71/71 exact-N、25,197/25,197 SMILES 可解析、0 cache reads、0 UniMol occurrence；
9. 先运行代码静态检查和 `check-only`，向用户汇报并再次请求正式 API 运行许可。

不应在同一版本中加入新阈值、新候选、新 Reviewer prompt 或其他模块，否则无法把正式收益归因于目标对齐。
