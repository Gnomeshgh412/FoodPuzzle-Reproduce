# 第十一轮：MFP 检索信息覆盖与 MPC 风险门控复现审查

日期：2026-08-09  
结论：MFP 未通过并停止；MPC 在冻结方法实施前因第十轮无法精确复现而停止，属于工程问题，尚不能评价 `KEEP_H1` 方法。

## 一、授权与边界

用户在看到双任务瓶颈、唯一改动、评测方案和停止条件后两次明确回复“允许”。本轮按双任务独立原则执行：

- MFP 只改 Scientist 可见的 BM25 demonstrations 数量；
- MPC 只计划在第十轮冻结 proposal 上新增风险受控 `KEEP_H1`；
- 两个任务没有共享标签、结果或评测信息；
- 未读取正式 test，未覆盖旧结果/cache，未修改正式评测器，未执行 Git 写操作；
- 方法不读取 raw FlavorDB 额外字段；raw DB 只在既有官方 MFP 类别评测器内使用。

## 二、本轮前的阶段瓶颈证据

### 2.1 MFP

现有完整 Scientific Agent 在 71 条 dev 上的阶段分解为：

- Scientist 第一候选宏类别 accuracy：`25/71 = 0.352113`；
- Scientist Top-3 宏类别 oracle：`41/71 = 0.577465`；
- Reviewer 宏类别 accuracy：`25/71 = 0.352113`；
- Reviewer 的 46 条错误中，30 条是 Scientist 三候选类别缺失，16 条是选择损失。

因此本轮先处理 Scientist。567 条 train 的 exact-profile grouped 5-fold 检索诊断表明，BM25 宏类别 oracle 从 Top-3 `0.580247` 升到 Top-10 `0.800705`，且五折都提高。dev 上对应数值为 `0.563380 → 0.816901`。

第一性原理判断是：正确类别支持已经存在于合法训练示例中，但 Top-3 检索过早丢弃它们。新方法不新增数据或模型，只检验 Scientist 能否把已有 Top-10 检索信息转化为更好的三候选。

### 2.2 MPC

在 568 条 train 的 exact-profile grouped 5-fold OOF 中，仅用各折 processed task 训练 profile 的分子候选：

- H1@N 具体分子 micro recall：`0.774757`；
- H1@1.25N / 1.5N / 2N / 3N：`0.805619 / 0.829573 / 0.861505 / 0.898972`；
- 各折任务内训练候选域上限：`0.971161`。

这证明很多正确分子已在 N 后近边界，但 exact-N 要求新增与安全移除同时成立。第十轮候选效用方法已在 train OOF 上得到稳定具体分子增益，但 dev 官能团增益区间跨零，且有 27 条 train OOF 查询的具体分子 F1 下降。本轮因此只准备检验证据不足时 `KEEP_H1`。

## 三、文献对应与适用边界

### 3.1 MFP

- Retrieval-Augmented Generation（NeurIPS 2020）支持在生成前使用非参数训练记忆补充参数模型：https://proceedings.neurips.cc/paper/2020/hash/6b493230205f780e1bc26945df7481e5-Abstract.html
- Multiple Choice Learning（NeurIPS 2012）支持以 best-of-K 任务损失审查有限结构化候选集：https://proceedings.neurips.cc/paper_files/paper/2012/hash/cfbce4c1d7c425baf21d6b6f2babe6be-Abstract.html

可借鉴的只是“检索信息要在生成前保留”和“要审查候选集 oracle”。它们不能证明增加 K 必然能让 FoodPuzzle Agent 利用额外示例。

### 3.2 MPC

- Recall-then-Verify（ACL 2022）支持区分候选召回与后续验证：https://aclanthology.org/2022.acl-long.128/
- Selective Classification for Deep Neural Networks（NeurIPS 2017）支持以 risk-coverage 审查接受/拒绝：https://proceedings.neurips.cc/paper/2017/hash/4a8423d5e91fda00bb7e46540e2b0cf1-Abstract.html

本项目只借鉴“证据不足时保持 H1”，不使用 dev Gold 或官能团标签训练门控。

## 四、冻结方法

### 4.1 MFP

唯一改动：`bm25_top_k: 3 → 10`。以下全部冻结：

- Scientist Prompt 和三个具体食物候选；
- Reviewer Prompt 和选择方式；
- DeepSeek `deepseek-v4-flash`；
- 固定官方证据、answer masking、5 个起始分子、每分子 3 条证据；
- train/dev split 和官方类别映射器。

对照为同轮瓶颈补证中已冻结的 K=3 完整 Agent dev 结果。准入同时要求：

1. Scientist Top-3 宏类别 oracle 增益的 paired bootstrap 95% 下界大于 0；
2. Reviewer 宏类别 accuracy 增益下界大于 0；
3. Reviewer 增益在 5 个固定 ID 交错分块中至少 4 块非负；
4. 71 条都解析成功，不直接输出宏类别。

### 4.2 MPC

唯一计划改动是在第十轮 proposal 上使用“最低被接纳 residual 分数−最高被移除 H1-only 分数”作为 margin，通过 train-only nested OOF 学习风险受控覆盖；不通过时 `KEEP_H1`。

但工程准入先于方法实施：必须精确复现第十轮 568 条 OOF 预测与关键指标，任一不一致即停止。

## 六、MFP 结果审查

### 6.1 官方主指标与阶段上限

| 指标 | K=3 对照 | K=10 | 增益 |
|---|---:|---:|---:|
| Scientist 第 1 候选宏类别 accuracy | 0.352113 | 0.366197 | +0.014085 |
| Scientist 第 2 候选宏类别 accuracy | 0.239437 | 0.267606 | +0.028169 |
| Scientist 第 3 候选宏类别 accuracy | 0.352113 | 0.309859 | -0.042254 |
| Scientist Top-3 宏类别 oracle | **0.577465** | **0.577465** | **0.000000** |
| Reviewer 宏类别 accuracy | **0.352113** | **0.352113** | **0.000000** |

- Scientist oracle 增益 paired bootstrap 95% 下界：`-0.070423`；
- Reviewer 增益 paired bootstrap 95% 下界：`-0.056338`；
- Reviewer 五个固定分块增益：`-0.066667 / +0.071429 / 0 / +0.071429 / -0.071429`，只有 3/5 非负；
- 两项主准入线均失败。

### 6.2 具体食物诊断

| 指标 | K=3 | K=10 |
|---|---:|---:|
| Scientist Top-1 具体食物命中 | 1/71 | 2/71 |
| Scientist Top-3 具体食物召回 | 2/71 | 2/71 |
| Reviewer 具体食物命中 | 0/71 | 2/71 |
| Reviewer 直接输出宏类别 | 0 | 0 |

具体食物 Top-1 有局部增加，但 Top-3 召回不变，且官方主指标完全不变。它不能使本方法准入。

### 6.3 机制结论

本轮否定的不是“Top-10 检索中没有额外正确类别信息”，而是：

> **只把更多检索示例填入现有长 prompt，不足以让 Scientist 将这些信息转化为更高的三候选类别覆盖。**

K=10 改变了各位候选的准确率，但对 Top-3 集合 oracle 和 Reviewer 都没有净改善。这说明下一轮不能继续调 K，也不能把检索 oracle 误当为 Agent 能力。

## 七、最终结论与停止

### MFP

**未通过并停止。**

- 不准入主方法；
- 不继续尝试 K=5、K=20 或更大 K；
- 不修改 Prompt 或 Reviewer 挽救本轮；
- 后续需要重新定位“Scientist 为什么无法把检索支持组织成互补三候选”，不得直接沿用“检索覆盖不足”假设。

### MPC

**工程问题，尚不能评价方法。**

- `KEEP_H1` gate 没有被训练，不能宣称成功或失败；
- 下一步必须先找回第十轮依赖的准确代码快照，或从已冻结产物重建可验证的 candidate ledger；
- 不得在当前漂移基线上继续门槛、特征或模型实验。
