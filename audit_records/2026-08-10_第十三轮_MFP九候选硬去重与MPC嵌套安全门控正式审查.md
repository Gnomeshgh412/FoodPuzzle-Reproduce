## 二、MFP：冻结九候选池的分支均衡硬去重

### 2.1 瓶颈与第一性原理

第十二轮不是“没有生成多样候选”，而是池化时固定取三个分支的第一名，导致共同证据中的高显著食物字符串反复占据有限三个槽位。九候选池平均仍有 5.6479 个不同具体食物，说明主要信息损失发生在集合选择阶段。

本轮借鉴 MMR 的“相关性与对已选集合的新颖性共同决定集合”思想，以及 Diverse Beam Search 对标准高概率生成同模态重复的分析。但本项目没有合法的候选食物完整分子谱，也不能控制 DeepSeek beam，因此只采用最小、可归因的硬去重池化，不照搬其打分或解码机制：

- Carbonell & Goldstein, SIGIR 1998, MMR：https://doi.org/10.1145/290941.291025
- Vijayakumar et al., AAAI 2018, Diverse Beam Search：https://ojs.aaai.org/index.php/AAAI/article/view/12340

### 2.2 唯一改动与冻结条件

按分支 1→2→3，各取本分支内排名最高且尚未选过的具体食物；不足三项时，再按分支内排名、分支序号从全池补足。候选原 rationale 保留。Reviewer 使用第十二轮原 Prompt、Top3 demonstrations 与证据重新选择。

探索保留预注册要求：Scientist Top3 宏类别 oracle 高于 K3 的 0.577465；Reviewer accuracy 高于 0.352113 且 wins>losses；具体食物 Top3 至少 2/71；71/71 成功且不直接输出类别。

### 2.3 结果

| 指标 | K3 | 本轮 | 变化 |
|---|---:|---:|---:|
| Scientist Top3 宏类别 oracle | 0.577465 | 0.563380 | -0.014085 |
| Reviewer 宏类别 accuracy | 0.352113 | 0.323944 | -0.028169 |
| Scientist Top3 具体食物命中 | 2/71 | 2/71 | 0 |
| Reviewer 具体食物命中 | 0/71 | 1/71 | +1 |

补充诊断：

- 三个候选槽位单列 accuracy 为 0.366197 / 0.169014 / 0.408451；
- 71/71 样本的三个候选均不同，直接宏类别输出为 0；
- Scientist oracle 增益 bootstrap 95% 区间为 `[-0.070423, 0.042254]`；
- Reviewer 增益区间为 `[-0.098592, 0.042254]`，配对结果 `2 wins / 4 losses / 65 ties`；
- Reviewer 五个固定分块增益为 `-0.066667 / -0.142857 / +0.071429 / +0.071429 / -0.071429`。

### 2.4 结论

**未通过并停止。**

硬去重确实解决了“表面重复”，却降低了候选类别 oracle，证明重复本身不是第十二轮失败的充分瓶颈；较低排名的未重复候选并不自动携带更多任务有效信息。不能继续围绕去重规则调顺序、权重或阈值挽救。本轮也说明：第三轮 MMR 的局部正信号不能被简化成“候选不同即可”，其相关性项和分子谱新颖性项可能共同发挥作用，而当前合法输入无法直接复现后者。

## 三、MPC：嵌套 OOF 查询级后置安全门控

### 3.1 瓶颈与第一性原理

第十二轮 proposal 新增 919 个 Gold，却移除 1013 个 H1 Gold。主要问题不是候选中没有正确分子，而是候选级排序被无条件转换成 exact-N 集合交换，没有判断某条查询是否值得执行 proposal。

本轮借鉴选择性预测与 post-hoc deferral 的“基础预测冻结、证据不足时回退”机制；不照搬分类或人工专家设定，而把动作改为两个 exact-N 分子集合之间的选择：

- Geifman & El-Yaniv, ICML 2019, SelectiveNet：https://proceedings.mlr.press/v97/geifman19a.html
- Narasimhan et al., NeurIPS 2022, Post-hoc Estimators for Learning to Defer：https://proceedings.neurips.cc/paper_files/paper/2022/hash/bc8f76d9caadd48f77025b1c889d2e2d-Abstract-Conference.html

### 3.2 唯一改动与防泄漏设计

gate 只使用推理时可得的 `[log1p(N), 交换数/N, H1与ICL共识数/N]`，固定逻辑回归 `C=1`、`liblinear`、阈值 0.5、种子 20260810、不标准化。目标为 proposal 相对 H1 的具体分子净命中是否为正，ties 排除，按净命中差绝对值加权。

训练采用严格嵌套 OOF：每个外折既不参与自己的排序器训练，也不参与 gate 训练；gate 的训练 proposal 再由其余四折内层 OOF 产生。只有训练准入全部通过后才读取 dev Gold。

### 3.3 训练 OOF 结果

| 指标 | H1 | 原 proposal | 门控后 |
|---|---:|---:|---:|
| 具体分子 macro F1 | 0.664915 | 0.678413 | 0.680573 |
| 具体分子 micro F1 | 0.775655 | — | 0.777469 |

- macro 增益 `+0.015658`，bootstrap 95% 区间 `[0.009412, 0.022122]`；
- `76 wins / 27 losses / 465 ties`；235 条 APPLY，333 条 KEEP；
- 五个外折增益全部为正：`+0.009310 / +0.029776 / +0.010359 / +0.007259 / +0.021564`；
- 568/568 exact-N；训练 OOF 全部预注册准入条件通过。

### 3.4 dev 结果

具体分子：

- macro F1 `0.694117 → 0.712008`，增益 `+0.017891`；
- micro F1 `0.774138 → 0.780613`，增益 `+0.006475`；
- `10 wins / 5 losses / 56 ties`；28 条 APPLY，43 条 KEEP；
- 71/71 exact-N，官能团缓存缺失 0。

官方官能团：

- F1 `0.649100 → 0.654204`，点估计增益 `+0.005104`；
- 配对结果 `12 wins / 9 losses / 50 ties`；
- bootstrap 95% 区间 `[-0.005340, 0.017286]`，跨 0；
- 五个固定分块增益为 `+0.010992 / +0.030159 / -0.004930 / -0.007179 / -0.003942`；
- N≤50、51≤N≤100、N>100 三组增益分别为 `+0.011252 / +0.002796 / 0`，没有观察到 N 子集下降。冻结方案未为“灾难性”预设事后数值阈值，因此只如实报告，不新造阈值。

### 3.5 结论

**获得局部信号并探索保留，不冻结论文主方法。**

该方向满足冻结的点估计、具体分子安全性、wins/losses 与 exact-N 条件，也在严格训练嵌套 OOF 上表现稳定，说明“查询级选择是否执行交换”确实比继续无条件改候选级排名更接近真实瓶颈。但 dev 已被多轮自适应复用，且官方官能团增益区间跨 0、五分块仅 2/5 为正，现有证据不足以称为稳定官方提升。后续若保留该方向，优先需要未触碰样本或独立重复验证，而不是在当前 dev 上继续调 gate。

## 四、本轮总体结论与下一轮约束

- MFP：候选“重复”是症状，不是当前最大充分瓶颈；硬去重路线停止。下一轮必须重新审查为什么九候选池中的较低位候选任务有效性差，以及 Scientist 的有效类别支持在哪一步丢失，不能继续微调去重规则。
- MPC：最大瓶颈已从“无条件交换”推进到“局部有效但官方稳定性证据不足”。后续不得在当前 dev 上调阈值、特征或按 N 制定规则；应优先设计不接触该 dev 的复验方案，或重新审查 gate 的可迁移信息是否充分。
- 本轮没有任何方法被认定为论文主方法最优版本。
